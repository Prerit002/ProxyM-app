# ProxyM User Flows

1. **Onboarding:** Splash -> Welcome -> Login/Register.
2. **Proxy Addition:** Home -> Add Proxy -> Input details -> Save -> (Sync to cloud if Premium).
3. **Proxy Testing:** Proxy List -> Tap 'Test' (single) or 'Test All' (bulk for Premium) -> View Status/Latency.
4. **Subscription Upgrade:** Settings -> Premium -> Select Plan -> Google Play Purchase -> Backend Verifies -> Premium Unlocked.
5. **Support Chat:** Support Center -> New Conversation -> Send Message -> (Admin replies via web) -> Receive notification -> View reply.
