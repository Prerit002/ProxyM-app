# ProxyM Feature List

1. **Authentication:** Register, login, logout, password reset, token mgmt.
2. **Proxy Management:** Add, edit, delete, group, import (TXT/CSV/Paste), export (TXT/CSV). Supported protocols: HTTP, HTTPS, SOCKS4, SOCKS5. Formats: `IP:PORT`, `IP:PORT:USER:PASS`, `USER:PASS@IP:PORT`.
3. **Proxy Testing:** Single/bulk test, latency, status (working, dead, timeout, etc.), IP/Country/ISP detection.
4. **Subscriptions:** Free vs Premium access control, Google Play integration.
5. **Notifications:** Push (FCM), in-app notification center, read/unread status.
6. **Support Chat:** Real-time messages, attachments, chat history, offline sync.
7. **Admin Panel:** Dashboard, user management, proxy stats, push notification trigger, real-time agent replies.
