# ProxyM Navigation

**Router:** GoRouter (Flutter)

**Map:**
- `/` -> Splash
- `/onboarding` -> Onboarding
- `/auth/login` -> Login
- `/auth/register` -> Register
- `/home` -> Home (BottomNav)
  - `/proxies` -> Proxy List
  - `/proxies/add` -> Add Proxy
  - `/proxies/edit/:id` -> Edit Proxy
  - `/test/:id` -> Single Test
  - `/bulk-test` -> Bulk Test
  - `/groups` -> Proxy Groups
- `/notifications` -> Notification Center
- `/support` -> Chat List
  - `/support/chat/:id` -> Active Chat
- `/premium` -> Subscription
- `/profile` -> Profile
- `/settings` -> Settings
