# ProxyM Design System

**Colors:**
- Primary: #007AFF (Blue)
- Background (Dark): #121212
- Surface: #1E1E1E
- Text (Primary): #FFFFFF
- Text (Secondary): #A0A0A0
- Success: #34C759
- Error: #FF3B30
- Warning: #FFCC00

**Typography:**
- Font: Inter (or Roboto)
- H1: 24sp, Bold
- H2: 20sp, Semi-bold
- Body: 16sp, Regular
- Caption: 12sp, Regular

**Components:**
- Buttons: Rounded corners (8dp), solid color for primary, outline for secondary.
- Cards: Elevation 2dp, rounded corners (12dp).
- Inputs: Outlined text fields.

*(Ponytail note: Native Material 3 handles 90% of this out of the box in Flutter. Use defaults where possible.)*
